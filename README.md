# 📊 Análisis de Optimización Comercial: AluraStore Latam

Este proyecto realiza un análisis integral de datos sobre el rendimiento de cuatro sucursales de venta retail para el cliente **Don Juan**. El objetivo principal es identificar la rentabilidad, eficiencia logística y satisfacción del cliente para fundamentar una decisión estratégica de desinversión.

## 🚀 Resumen del Proyecto
A través del procesamiento de datos con **Python** y **Pandas**, se evaluaron métricas  de cada tienda para determinar cuál de ellas presenta un bajo rendimiento y representa un riesgo financiero para la expansión del negocio.

* **Lenguaje:** Pyton
* **Librerías de Análisis:** Pandas, NumPy
* **Visualización:** Matplotlib, Seaborn
* **Entorno:** Google Colab 

## 📈 Análisis Realizado
El flujo de trabajo del notebook incluye:
1. **Importación de Datos:** Carga de bases de datos individuales por tienda desde repositorios remotos.
2. **Limpieza y Procesamiento:** Estandarización de columnas de precios, costos de envío y calificaciones.
3. **Análisis por Categoría:** Identificación de los productos más y menos vendidos, asociándolos a su categoría estratégica.
4. **Comparativa de KPIs:**
   * **Ingresos Totales:** Quién genera mayor flujo de caja.
   * **Costo de Envío Promedio:** Evaluación de la eficiencia logística.
   * **Calificación (Rating):** Medición de la satisfacción del cliente.

## 🏆 Veredicto Estratégico
Tras el análisis, se determinó que la **Tienda 4** es la unidad con menor rendimiento. A pesar de tener costos de envío bajos, su incapacidad para generar volumen de ventas en categorías clave (como Electrónicos) y su baja calificación de clientes la convierten en la candidata ideal para ser liquidada.
